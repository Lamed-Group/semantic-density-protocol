# Протокол семантической плотности v0.1

Статус: **экспериментальная пилотная спецификация**

## 1. Объект измерения

Протокол не присваивает тексту независимую от наблюдателя плотность. Он фиксирует наблюдение:

    O = (конструкт, линза, контекст, время)

и вычисляет:

    P_набл(O) = N(O) * E(O) / D(группа)

Сравнивается не «текст вообще», а наблюдения, полученные в явно описанных условиях.

## 2. Основные переменные

### 2.1 Смысловые узлы: N

Смысловой узел — утверждение, различение, отношение, вопрос, метафора или операциональная инструкция, которую можно пересказать, но нельзя удалить без потери части функции конструкта.

Для каждого наблюдения:

    N = количество выделенных смысловых узлов

В данных сохраняется не только число, но и список узлов.

### 2.2 Энергия резонанса: E

В пилотной версии:

    E = время осмысления / время чтения

Время чтения должно быть больше нуля. Время осмысления — измеренное или сообщённое наблюдателем время активной обработки конструкта после первичного чтения.

Оценочные времена обязательно помечаются как оценки. В перспективном исследовании предпочтительны измеренные значения.

### 2.3 Интерпретационный разброс: D

D является свойством группы наблюдений. Участники независимо отвечают одним предложением на вопрос «О чём этот текст?». Ответы группируются по существенно различным интерпретациям.

Пилотное определение:

    D = количество кластеров интерпретаций

Ответ «не могу определить смысл» сохраняется как значимый результат. Такого участника нельзя заменять другим.

В следующих версиях простой подсчёт может быть дополнен нормированной энтропией или коэффициентами согласия.

### 2.4 Наблюдаемая плотность: P_набл

Для каждого наблюдения j:

    P_набл_j = N_j * E_j / D_группы

Значение имеет смысл только вместе с линзой, контекстом, списком узлов, способом измерения времени, процедурой получения D и версией протокола.

## 3. Линза

Каждое наблюдение содержит профиль линзы:

- тип: человек, языковая модель, гибрид или неизвестно;
- язык;
- знакомство с предметной областью;
- предварительное знакомство с конструктом;
- уровень предоставленного контекста;
- режим анализа;
- для ИИ: название модели, дата, доступные системные инструкции и краткое описание истории контекста.

В v0.1 линза не получает произвольного числового коэффициента.

## 4. Контекст

Уровень контекста:

- отсутствует;
- минимальный;
- полный;
- обученный или откалиброванный;
- пользовательский с описанием.

Один и тот же конструкт может измеряться при разных уровнях контекста. Каждое изменение контекста создаёт новое наблюдение.

## 5. Ограничение Эшби

Закон необходимого разнообразия используется как ограничение измерения:

    если V_линзы < V_требуемого_конструктом,
    часть конструкта не может быть различена этой линзой.

В v0.1 числовое значение разнообразия не вводится. Ограничение проявляется через профиль линзы, пропущенные узлы, ответы «не понял» и разброс результатов между линзами.

## 6. Агрегация

Отчёт должен по возможности включать:

- медиану P_набл;
- минимум и максимум;
- межквартильный диапазон;
- группы линз;
- согласованность выделения узлов;
- количество кластеров интерпретаций;
- долю нераспознанных текстов;
- долю измеренных и оценочных времён.

Среднее число нельзя представлять как внутреннее объективное свойство текста.

## 7. Исторические расчёты

Расчёты, выполненные до v0.1, сохраняются с пометкой:

- record_type = historical;
- исходные N, E, D и P;
- ссылка;
- замечания об оценочных данных и изменявшейся шкале.

Без повторной разметки они не включаются в откалиброванный benchmark.

## 8. Экспериментальные расширения

Время жизни, инструментальность, архетипическая завершённость, сила метафоры, автобиографическая подлинность, стратегическая операциональность и коэффициент «гы» учитываются отдельно от основной P_набл.

## 9. Что показатель не измеряет

P_набл не является непосредственной мерой:

- истины;
- фактической точности;
- морали;
- интеллекта;
- сознания;
- безопасности;
- литературного качества;
- значимости автора.

Это операциональный показатель того, какая смысловая структура стала различимой и резонансной в зафиксированных условиях.
