# Протокол семантической плотности

**Экспериментальный протокол аннотирования семантической плотности как взаимодействия конструкта, контекста и наблюдающей линзы.**

Версия: **0.1.0 (пилотная)**

Автор: **Alexander Gorin / Lamed Group**

Канонический источник методики:
https://www.lamedgroup.info/semantic-density-methodology/

## Основная идея

Семантическая плотность не считается неизменным свойством текста. Протокол фиксирует плотность, которая становится наблюдаемой при встрече конкретной линзы с конкретным конструктом в конкретном контексте:

    P_набл = P(конструкт | линза, контекст)

Пилотная операциональная формула:

    P_набл = N * E / D

где:

- **N** — количество смысловых узлов, различённых линзой;
- **E** — энергия резонанса: отношение времени осмысления ко времени чтения;
- **D** — интерпретационный разброс между наблюдениями.

Полученное число является экспериментальным диагностическим показателем. Оно не измеряет истинность, качество, безопасность или интеллект.

## Ограничение линзы по Эшби

Закон необходимого разнообразия У. Росса Эшби используется как ограничение интерпретации. Если линза не обладает достаточным разнообразием различений, чтобы соответствовать разнообразию конструкта, часть структуры схлопывается в неразличимый шум.

Поэтому линза обязательно сохраняется в данных. Низкая наблюдаемая плотность может означать как низкую плотность конструкта, так и недостаточную разрешающую способность линзы.

Подробнее: [docs/ASHBY_LENS.md](docs/ASHBY_LENS.md).

## Быстрый запуск

Требуется Python 3.10 или новее.

    python -m pip install -e .
    semantic-density score --nodes 18 --reading-seconds 600 --reflection-seconds 1800 --dispersion 5

Проверка:

    make validate
    make test

Сборка каталога для Hugging Face:

    make hf

## Статус данных

Пилотный корпус содержит:

1. иллюстративное сравнение трёх управляющих сигналов;
2. индекс исторических расчётов, опубликованных Lamed Group.

Исторические оценки создавались в процессе развития методики. Они сохранены как происхождение и материал для повторной калибровки, а не как готовый эталон.
