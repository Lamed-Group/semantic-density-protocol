# Contributing

Contributions are welcome when they preserve the protocol's central distinction: semantic density is observed through a declared lens, not extracted as a context-free property of text.

## Useful contributions

- Independent annotations, including explicit non-answers.
- Replication studies with a predeclared lens and context.
- Better dispersion measures and inter-rater analysis.
- New language and culture profiles.
- Corrections to schemas, validators, and documentation.

## Submission checklist

1. Do not silently delete failed, incomplete, or non-interpreting observations.
2. Record the lens, context level, language, instructions, timing method, and date.
3. Keep the core N, E, and D variables separate from experimental extensions.
4. Mark illustrative or historical records clearly; do not relabel them as calibrated.
5. Add or update tests when changing code.
6. Run `make check` before opening a pull request.

By contributing original documentation or annotations, you agree to publish them under CC BY 4.0. Code contributions are licensed under Apache-2.0.
