# Annotation guide

## Unit of work

One annotation represents one lens observing one construct in one declared context.

## Procedure

1. Register the construct without rewriting it.
2. Register the lens profile and context before interpretation.
3. Measure reading time.
4. Ask the observer to list semantic nodes.
5. Ask for a one-sentence interpretation.
6. Measure or collect reflection time.
7. Preserve non-understanding, rejection and ambiguity as data.
8. Cluster interpretations only after all independent responses are collected.
9. Calculate N, E, D and P_observed.
10. Record uncertainty and whether times were measured or estimated.

## Semantic-node test

A candidate is a semantic node when:

- it can be paraphrased as a distinct proposition, relation, question, image or instruction;
- removing it changes what the construct can do;
- it is not merely a stylistic repetition.

Do not count every sentence automatically. One sentence may contain several nodes, and several sentences may express one node.

## Interpretation clusters

Two interpretations belong to the same cluster when they preserve the same central relation or operational conclusion. Differences in wording alone do not create a new cluster.

Retain these as valid clusters when present:

- no meaning detected;
- incoherent or noise;
- literal-only reading;
- metaphorical reading;
- operational reading;
- adversarial or rejection reading.

## Timing

Measured timing is preferred. If reflection continues intermittently, record:

- first continuous reflection period;
- later return events;
- measurement window.

The core E value uses the first declared reflection period. Later returns may be stored as extension data.

## AI observations

For an AI lens, preserve:

- exact input;
- available model label;
- date;
- context supplied;
- role or system instruction when available;
- whether the output was sampled once or repeatedly;
- output used to extract nodes and interpretation.

Do not infer hidden internal states or consciousness from the annotation.

## Quality control

Recommended pilot minimum:

- 5 independent lenses per construct;
- at least 2 annotators reviewing node boundaries;
- no deletion of non-answers;
- re-annotation of 20 percent of observations;
- explicit protocol version on every row.
